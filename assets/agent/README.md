# Avatar asset credits

The avatar is based on Wobble Blocks' *PS2 Styled Characters*, released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The [author's asset page](https://opengameart.org/content/ps2-styled-characters) contains the original downloads.

The baked standing and crouching mesh in `mesh.bin` preserves Surfd's adaptation of the CC0 base geometry, as described in [Surfd's asset notices](https://surfd.net/licenses/map-and-code.txt).

The 256 by 256 atlas uses the original `Masc_Texture01.png`, `hair_brown.png`, and `eye_0001_c.jpg` from [the author's base archive](https://opengameart.org/sites/default/files/ps2characterbase_0.zip). The body texture is copied at native resolution and the hair and eye textures are resampled to their existing UV tiles. The remaining area is filled with neutral charcoal.
